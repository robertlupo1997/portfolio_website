PUBLIC NOTICE — pursuant to Filing half-blood-prince, each page of a PDF or EPUB is hereby submitted to a language model, and its margin notes are burned back into the book: ink marks, handwriting-style notes, connector arrows.

Structured output is negotiated per provider with documented downgrade chains, then re-validated locally. Anchoring matches exact quotes through an exactness-tier ladder; ambiguity fails closed. Unmatched notes are skipped with typed reasons, never guessed.

Margin placement is set by an integer beam solver — overlap, connector-crossing, and displacement costs resolved without conflict.

KKBOX Churn Prediction

0.9696 AUC (validation) · isotonic calibration

Ranking is not probability. A LightGBM ranker reached 0.9696 AUC on a train-past, validate-future split, and isotonic calibration brought log loss from 0.4130 to 0.1127. Both are tuned-validation numbers: the hyperparameters were selected on that same window, so no untouched test set stands behind them. The repository states this first.

The live demo is not that model. It serves an XGBoost model retrained on the 10,000-member sample the repository actually ships, scored on a 1,995-member holdout at 0.9765 AUC, with the calibrator applied at request time. Calibration costs it log loss there — 0.1534 to 0.1677 — which is the honest direction when the raw scores were already sharp. Source: github.com/robertlupo1997/kkbox-churn-prediction · Live: huggingface.co/spaces/robertlupo1997/kkbox-churn-prediction.
