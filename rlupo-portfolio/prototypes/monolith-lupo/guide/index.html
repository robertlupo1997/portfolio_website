The brief

The previous run adapted monolith's style into a 3-slide carousel and lost what made it good: six full-viewport posters, scroll-snapped, each a different composition at oversized scale. This run's contract: copy monolith's structure verbatim — scroll-snap poster pages, side rail, Archivo Black + Inter Tight, ink/concrete/orange, registration marks, hover grid, concrete texture, cover scramble — and replace every fictional civic filing with a real one from constants.ts. The civic-notice voice becomes the resume voice. One motion set-piece per poster, entrance-triggered. Never invent a fact, metric, employer, or date.

Signature technique

Every metric on the page is the true value in static HTML — JavaScript only animates toward the truth. The RMSLE set-piece counts down from 1.00 to 0.48, because for forecast error, decreasing is the achievement:

/* Poster 4 — bars draw first, then the RMSLE resolves 1.00 → 0.48
   (the error coming down is the point) */
function runHrfCountdown() {
  const el = document.querySelector('[data-countdown]');
  if (!el) return;
  if (reducedMotion) { el.textContent = '0.48'; return; }
  window.setTimeout(() => {
    animateNumber(el, 1.0, 0.48, 1100, (v) => v.toFixed(2));
  }, 850);
}

All entrance choreography is gated on a single html.js-anim class that is added only when JS runs and the user allows motion — so no-JS and reduced-motion visitors get the complete static composition, never a blank stage. One IntersectionObserver stamps .is-in per poster; CSS transition-delays do the sequencing (notice rows stamp in, register rows print, chips stamp last, the orange block slides, link underlines draw on a stagger).

The motion pass — print-shop physics, chaos gridded underneath

A second directed build (Trey: "go nuts — inside the grid"). Eight set-pieces, every one an artifact of print production, never web-slop. All of it rides the existing gates: html.js-anim for entrances, reduced-motion and no-JS get the finished composition, transform/opacity only, rAF loops pause on hidden tabs, zero libraries.

  • P2 — misregistration settle (the signature). VARIANCE / ANALYSIS arrive as misregistered overprints: an orange plate copy (::before, content: attr(data-text)) sits 3px off the ink and slides into perfect register as the poster enters, then vanishes. The corner registration marks, made literal. The orange copy is decorative pseudo-content behind AA-passing ink text, on screen for under a second — reduced-motion users only ever see registered ink.
  • P3 — benchmark race. Under the 3.9×: two plotter pens run the same wall-clock, FerroML's ink trail ending 3.9× further than sklearn's (--f: 1 vs 0.2564 — the true ratio). Static and reduced-motion pages ship the finished race; JS re-runs it with the count-up's own duration and easing.
  • P4 — forecast split. After the bars print, a dashed fit line (SVG polyline over the bar tops) sweeps across on a linear clip-path reveal — and as it crosses the seam at bar 34, the last ten bars lift from solid ink to outlined plates, timed to the sweep (delay = i·30ms − 150ms). Fine print marks the seam: ACTUAL → | → FORECAST.
  • P5 — scanline registration. A 2px orange line sweeps the register once (the bottom edge of a full-height strip, translateY −100% → 0, clipped by the list's own overflow) and every status chip stamps as the line passes its row — chip delays retimed from a flat stagger to 0.43s + i·169ms to track the linear sweep. The docket's newest line types in character-by-character under the blinking caret.
  • P6 — date-stamp arrival. OPEN TO WORK lands as individual stamp strikes: JS splits the lines into letter spans, each scaling 1.25 → 1 on the thud bezier, 26ms apart in one continuous pass. The CTA takes a quiet ready-pulse every 7s (scale 1.012, suspended under hover/focus so the hover transform wins).
  • P1 — plotter rules + live letters. The cover rules are drawn by an 8px orange carriage that rides the ink edge and vanishes at the end of the line (the carriage is the right-edge block of a full-width strip sliding translateX −100% → 0, so it can never desync from the scaleX draw). Hovering any settled title glyph re-scrambles just that glyph for 350ms, then it locks (pointer:fine only).
  • Site-wide — crosshair cursor. A registration-mark crosshair follows the pointer with mix-blend-mode: difference — white strokes, so it renders as the exact negative of every ground it crosses (light on ink, dark on concrete, cyan on orange: the mathematical complement). Spring-lagged ~80ms via an exponential rAF filter that sleeps when settled and on hidden tabs; scales 1.4× over links. The native cursor is never hidden.
  • Site-wide — proof sheet (press P). The imposition view: all six posters as a printer's contact sheet. Implementation choice — live same-document iframes, one per poster via ./#poster-N anchors, lazy-loaded on first toggle and scaled to the tile (JS measures the frame, sets --proof-scale). The tiles are living proofs: each mini poster runs its own entrance. Cost: six extra page instances on first open — accepted for desktop-only, keyboard-gated chrome; the CSS-abstraction fallback was the cheaper, deader option. Dialog semantics: role=dialog, aria-modal, focus trapped (close button + six labeled tiles), Enter jumps to the poster and exits, Esc exits, Ctrl/⌘+P never intercepted. ≤768px: not available.

Honest remaining concerns

  • The cover title sets at 14vw — monolith's MONOLITH fills harder at 15vw; "TREY LUPO" has a space, so the tradeoff went to letter-size consistency.
  • The FILE AN INQUIRY CTA points at mailto until Ask My Work has a live URL — re-point it at deploy time.
  • og:image and canonical assume https://treylupo.com/ — correct at deploy if the site lands on a subdomain.
  • The fine-print marginalia stays at 0.38 opacity by monolith precedent — defensible only because it is aria-hidden duplication of facts stated accessibly elsewhere.
  • The proof sheet's six live iframes are the honest cost of living tiles — lazy-loaded and desktop-only, but a first toggle on a slow machine will feel it. Swap to CSS-drawn abstractions if it ever matters more than the delight.
  • The misregistration overprint puts orange glyph-shapes on concrete for ~0.9s. AA is a property of text, and the text — the ink layer — never dips below 9:1; the orange is aria-hidden paint that reduced-motion users never see. Ruled compliant, noted because orange-on-concrete is otherwise banned on this site.
  • The crosshair renders cyan on the orange poster — that is what difference does to orange, the literal photographic negative. Ruled in-brief (registration marks are press hardware), but it is the one non-palette color on the site.
  • Printing within the first ~1.2s of load can still catch the cover scramble mid-flight (inline letter opacities) — a real but vanishing edge.
