The brief

The previous run adapted monolith's style into a 3-slide carousel and lost what made it good: six full-viewport posters, scroll-snapped, each a different composition at oversized scale. This run's contract: copy monolith's structure verbatim — scroll-snap poster pages, side rail, Archivo Black + Inter Tight, ink/concrete/orange, registration marks, hover grid, concrete texture, cover scramble — and replace every fictional civic filing with a real one from constants.ts. The civic-notice voice becomes the resume voice. One motion set-piece per poster, entrance-triggered. Never invent a fact, metric, employer, or date.

Signature technique

Every metric on the page is the true value in static HTML — JavaScript only animates toward the truth. The RMSLE set-piece counts down from 1.00 to 0.48, because for forecast error, decreasing is the achievement:

/* Poster 4 — bars draw first, then the RMSLE resolves 1.00 → 0.48
   (the error coming down is the point) */
function runHrfCountdown() {
  const el = document.querySelector('[data-countdown]');
  if (!el) return;
  if (reducedMotion) { el.textContent = '0.48'; return; }
  window.setTimeout(() => {
    animateNumber(el, 1.0, 0.48, 1100, (v) => v.toFixed(2));
  }, 850);
}

All entrance choreography is gated on a single html.js-anim class that is added only when JS runs and the user allows motion — so no-JS and reduced-motion visitors get the complete static composition, never a blank stage. One IntersectionObserver stamps .is-in per poster; CSS transition-delays do the sequencing (notice rows stamp in, register rows print, chips stamp last, the orange block slides, link underlines draw on a stagger).

Critique history — what each pass actually found

4 PASSES · 0 CONSOLE ERRORS

Pass 1 — desktop, posters 2/4/6

  • Found: marginalia collided with the notice header; the filing index was ink-on-ink over the PUBLIC NOTICE strip (read "ING 02/06"); the rail floated over poster 6's orange block in concrete — the exact fixed-chrome trap from the adoption run's post-mortem.
  • Fixed: marginalia dropped below the header line; filing index became an ink plate that survives every ground; data-rail override per poster.
  • Upgrade: certification seal on the notice; orange ::selection.

Pass 2 — desktop, posters 1/3/5

  • Found: the register wordmark clipped to "OJECT" — monolith clips "PUBLIC" as decoration, but here the word pairs with the heading as "PROJECT · REGISTER 2024–26" and has to read.
  • Fixed: sized to fit the column (7.6vw).
  • Upgrade: print stylesheet — the annual files itself on paper.

Pass 3 — mobile sweep + computational AA audit

  • Found: a 2px orange sliver at the top (the "hidden" skip-link peeking in); eyebrows overlapping corner registration marks on mobile; the footer credit overlapping the timeline's last row on poster 6 mobile.
  • AA audit (computed, not eyeballed): five failing text pairs, two inherited from monolith itself — notice header at ink@0.65 (3.92:1), rail numbers at 0.55 (≈3.5:1), mobile orange-ground text at ink@0.6–0.72 (2.69–3.29:1), cover colophon and footer at reduced opacity. All raised to passing values; on orange, only full ink passes (4.75:1), so mobile hierarchy comes from size and weight, not tint.
  • Upgrade: the G-key grid toggle; the stamp straightens 2° under the cursor.

Pass 4 — director verification

  • Found: on poster 6 the orange block's bottom edge crosses the rail — links 01–05 sat on orange (ink passes) but the active 06 sat below the edge on the ink field: ink on ink, invisible. No single float color survives a rail that straddles two grounds.
  • Fixed: on poster 6 the rail becomes an ink plate (echoing the PUBLIC NOTICE strip) — concrete numbers at 8.5:1, active in orange at 4.75:1, independent of whatever passes beneath.

Honest remaining concerns

  • The cover title sets at 14vw — monolith's MONOLITH fills harder at 15vw; "TREY LUPO" has a space, so the tradeoff went to letter-size consistency.
  • Ask My Work is listed "SSE" in the register — the least legible metric of the eight; it means streaming Server-Sent Events.
  • The fine-print marginalia stays at 0.38 opacity by monolith precedent — defensible only because it is aria-hidden duplication of facts stated accessibly elsewhere.
