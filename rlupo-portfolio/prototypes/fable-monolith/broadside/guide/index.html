Signature Technique

Fit-title: poster-scale headline that fills container width exactly

The hero title "TREY LUPO" must fill the content column width at every viewport. CSS clamp() approximates this, but VT323's character-cell width is non-standard and produces gaps. The solution: a binary-search fit function that measures scrollWidth against the available container width and converges on the largest integer pixel size that fits. It runs before the scramble (which wraps letters in spans) so measurement is clean, and re-runs on window resize via a 60ms debounce. 

/* From main.js — fitTitle() */
function fitTitle() {
  const el = document.getElementById('hero-title');
  if (!el) return;

  const parent = el.parentElement;
  const style  = window.getComputedStyle(parent);
  const maxW   = parent.clientWidth
    - parseFloat(style.paddingLeft)
    - parseFloat(style.paddingRight);

  el.style.fontSize = '1px';
  let lo = 1, hi = 600;
  while (lo < hi - 1) {
    const mid = Math.floor((lo + hi) / 2);
    el.style.fontSize = mid + 'px';
    if (el.scrollWidth <= maxW) lo = mid;
    else hi = mid;
  }
  el.style.fontSize = lo + 'px';
}

Form-feed slide transition

When a slide changes, a brief clip-path animation sweeps a near-opaque overlay from top to bottom — simulating a line-printer's form-feed advancing the paper. The animation is 90ms, triggered by adding/removing a class on the flash element. In reduced motion, the CSS override (animation-duration: 0.001ms) collapses the flash to instant, so no special JS branch is needed. 

/* style.css — form-feed flash */
@keyframes ff-scan {
  0%   { opacity: 0; clip-path: inset(0 0 100% 0); }
  35%  { opacity: 0.2; clip-path: inset(0 0 0% 0); }
  100% { opacity: 0; clip-path: inset(100% 0 0 0); }
}

.carousel__flash.active {
  animation: ff-scan 90ms cubic-bezier(0.4, 0, 0.6, 1) forwards;
}

VT323 taste gate (pass 1 verdict)

The brief required a judgment call in pass 1: does VT323 at hero scale read "DEC terminal" or "arcade game"? At poster scale (~200px), the pixelation becomes deliberate texture — each letter's blocky pixel grid reads as a CRT scan artifact, not a game sprite. The O in LUPO's octagonal hole and the R's pixelated serifs reinforce a typewriter-era authority rather than an 8-bit playfulness. Verdict: KEEP VT323. Swap to Martian Mono at port time if the client's eye reads differently.
