01

The Brief

Concept: the portfolio as a civic annual of fiscal filings. Every slide is an oversized public-notice poster — filed, stamped, registered. FP&A work rendered with the gravity of a municipal ordinance. The persona is a civic-signage screenprinter who sets budget-hearing notices by hand and believes a good poster is a legal document.

The palette is raw #b9b5ad concrete ground, #1c1a17 ink, #e8551a warning orange, and #f0ece4 cream. The critical constraint: orange on concrete fails AA at 1.79:1 — orange is strictly non-text decoration (rules, blocks, reg marks, stamps) on concrete panels. Orange text is permitted only on ink panels (4.75:1 passes).

Signature moves adopted from the monolith source: letter-by-letter scramble on the hero name (85ms stagger / 420ms settle, rAF, document-hidden guard); a hover/focus-revealed 12-column × 8-row grid skeleton per slide; the CSS concrete texture recipe (three layered repeating-linear-gradients + a base gradient); print-registration crosshairs; a vertical FILED ink strip; and a rotated rubber-stamp block (RECEIVED · 2026) with spring hover tilt.

The carousel is a horizontal translateX track — not scroll-snap. Three slides + one INDEX overlay. Full deep-link support (?slide=N, ?overlay=1), keyboard navigation (ArrowLeft/ArrowRight), focus trap in the overlay. The brief proves: a serious analyst's portfolio can be as loud and rigorous as a civic-design annual.

02

Signature Technique

The CSS concrete texture recipe — three layered repeating-linear-gradient passes at prime angles (−55°, 35°, 82°) plus a directional base gradient create the illusion of poured concrete aggregate without a single image asset. This is the load-bearing texture beneath every concrete-ground slide.

/* Concrete texture: 3 aggregate passes + directional base Applied to .slide--hero and .slide--project */ .slide--hero { background-color: var(--concrete); /* #b9b5ad */ background-image: repeating-linear-gradient( -55deg, transparent 0, transparent 4px, rgba(28, 26, 23, 0.018) 4px, rgba(28, 26, 23, 0.018) 5px ), repeating-linear-gradient( 35deg, transparent 0, transparent 7px, rgba(255, 255, 255, 0.01) 7px, rgba(255, 255, 255, 0.01) 8px ), repeating-linear-gradient( 82deg, transparent 0, transparent 11px, rgba(28, 26, 23, 0.01) 11px, rgba(28, 26, 23, 0.01) 12px ), linear-gradient(168deg, #c0bcb4 0%, var(--concrete) 45%, #b2aea7 100%); } /* Grid skeleton: 12 columns × 8 rows, revealed on hover/focus */ .grid-overlay--ink { --grid-col: rgba(28, 26, 23, 0.12); --grid-row: rgba(28, 26, 23, 0.06); } .slide:hover .grid-overlay, .slide:focus-within .grid-overlay { opacity: 1; /* fades in via 0.45s cubic-bezier(0.4, 0, 0.2, 1) */ }

The second signature move unique to ledger is the CSS filing fold — a document dog-ear in the top-right corner of the project slide. Two ::before/::after pseudo-elements on .slide--project create a linear-gradient triangle reading as a peeled corner.

/* Shadow wedge — bottom-left triangle of the corner square */ .slide--project::before { content: ''; position: absolute; top: 50px; /* clear fixed header */ right: 0; width: 0; height: 0; border-style: solid; border-width: clamp(3rem, 5.5vw, 5.5rem) clamp(3rem, 5.5vw, 5.5rem) 0 0; border-color: rgba(28, 26, 23, 0.2) transparent transparent transparent; z-index: 30; pointer-events: none; } /* Fold-back flap — brighter concrete face revealed */ .slide--project::after { content: ''; position: absolute; top: 50px; right: 0; width: clamp(3rem, 5.5vw, 5.5rem); height: clamp(3rem, 5.5vw, 5.5rem); background: linear-gradient( -135deg, var(--concrete-light) 50%, /* #ccc9c1 — brighter concrete = paper face */ transparent 50% ); z-index: 31; pointer-events: none; }

The third technique worth noting is the diagonal watermark band in the hero's upper zone. A ::after pseudo-element on .slide--hero contains the text "FISCAL RECORD · ANNUAL FILING · PUBLIC RECORD ·" at display scale, rotated −4°, at 3.8% opacity. It fills what would otherwise read as dead concrete and signals documentary authority without competing with the scramble headline.

03

The Three Surfaces

01

Hero / Introduction — Concrete Ground

The name slide. Concrete texture ground with FILED ink strip on the left edge (orange text on ink — 4.75:1 ✓). Giant H1 "TREY LUPO" with the letter scramble (85ms stagger, 420ms settle, rAF, reduced-motion skip). Full-width orange rule divides the name from the role line. A barely-visible embossed "LUPO" in the lower right uses text-shadow relief (transparent color, light/dark shadow pair). Diagonal "FISCAL RECORD" watermark at 3.8% opacity claims the upper zone. RECEIVED · 2026 rubber-stamp with spring hover tilt (cubic-bezier(0.34, 1.56, 0.64, 1)) at bottom left. Registration crosshairs at four corners. Grid skeleton on hover.

02

Project Poster — Renewal Notice

FILING F-2026-011 / HIERARCHICAL FORECASTING in the header. The title "REVENUE TELEMETRY" stacks as two lines — second word shifted right (padding-left: clamp(1.5rem, 7%, 7rem)) — creating the asymmetric tension of a civic renewal poster. Title fills 90%+ of the slide width at desktop. Dog-ear filing fold in the top-right corner (CSS triangle technique). Fine-print marginalia column with fictional filing statutes (§ 14.2(c), etc.) in the right dead zone. RECEIVED stamp rotated 1.8° at bottom-right. Detail grid (Stack / Status / Year) in a three-column dl.

03

Outro / Contact — Ink Ground

Ink ground with cream text (14.74:1). Orange rule is decoration only — non-text on ink panels satisfies the AA constraint. "THE RECORD IS OPEN." as the h2, "Six filings a year. One analyst." as the anchor line. Ghost "OPEN" text in the background at 4% opacity. Contact links in cream with orange-border underlines; hover shifts to orange (4.75:1 on ink ✓). Orange-tinted grid overlay on hover (vs. ink-tinted on concrete slides).

IDX

INDEX Overlay — Full-screen Ink Takeover

The INDEX dialog covers the full viewport at z-index 300. Cream "INDEX" heading at 11vw. Orange divider rule (decoration). Five entries span the full overlay height via flex justify-content: space-between. Entry 01 bears an orange left-border stripe distinguishing it from the inert (opacity 0.45) entries 02–05. Orange display-scale numerals (4vw, passes AA at large-text threshold of 3:1). Fine-print statute marginalia column on the right. Focus is trapped inside the overlay; Escape and CLOSE both call closeOverlay() and return focus to the INDEX button.

04

Critique History

Pass 01

Initial build — structure established

  • Hero: content clustered in lower third; upper 60% of concrete was a dead zone with no structural claim to that space.
  • Registration marks at reg-tl and reg-tr sat at 20px, hidden under the 50px fixed ink header.
  • Orange hero rule was capped at max-width 60%, creating a weak horizontal anchor.
  • Overlay: INDEX entry 05 "NIGHT SHIFT" clipped at viewport bottom — entry padding too loose for 5 items at 900px height.
Upgrade: CSS filing fold (dog-ear) added to project slide — triangular peel in top-right corner using ::before/::after CSS triangle technique.
Pass 02

Layout fixes + overlay sizing

  • Top registration marks moved from 20px to 60px to clear the fixed header. Now all four marks visible in their corners.
  • Hero center changed from justify-content: center to flex-end with padding-bottom — anchors the title block to the lower slide zone, creating the civic-poster effect of blank official space above content.
  • Orange rule extended to full width — now a firm visual floor under the h1.
  • Overlay entry padding reduced and numeral size tightened so all 5 entries fit. But this created an opposite problem: 50% dead zone in the overlay after entry 05.
  • Project slide description had an orphan — "discipline, one source of truth." on its own line.
Upgrade: faint horizontal reference line added at ~30% height on hero — suggests folded-paper registration, converts bare concrete to intentional document space.
Pass 03

Overlay fill + watermark + mobile fix

  • Overlay dead zone fixed: index-list changed to flex with justify-content: space-between; body changed to align-items: stretch so entries span the full overlay height evenly.
  • Entry 01 given an orange left-border stripe (3px solid orange) to distinguish it from inert entries — visible active filing marker.
  • Diagonal "FISCAL RECORD · ANNUAL FILING · PUBLIC RECORD ·" watermark added to hero's upper zone at 3.8% opacity (adjusted down from 5.5% which read too bold).
  • Vertical "PUBLIC RECORD · FISCAL ANNUAL" label added to right edge of hero, 0.6rem, writing-mode: vertical-rl — claims the right margin as intentional.
  • Mobile: eyebrow text wrapping fixed (font-size reduced to 0.58rem, nowrap with ellipsis). Hero center changed to justify-content: center on mobile to eliminate mid-screen dead zone.
  • Description text max-width tightened to 52ch + text-wrap: balance to prevent orphan line.
Upgrade: diagonal watermark band — the most distinctive document-aesthetic move in the study. Fills the upper dead zone with civic authority character without competing with the h1 scramble.
Pass 04 — Director catch

Carousel control contrast — release blocker found in post-build verification

  • Defect found by director verification, not self-review: .carousel-controls is position:fixed and persists over all slide grounds, but its colors were derived for the ink ground only. On the two concrete-ground slides (hero and project), .carousel-btn had color: var(--concrete) (#b9b5ad) against concrete (#b9b5ad) = 1.00:1 — the enabled NEXT button was literally invisible. .carousel-counter had color: var(--concrete-dark) (#8a8680) on concrete = 1.77:1, failing AA. Hover state color: var(--cream) on concrete = 1.73:1, making it worse. All three passed on the ink contact slide; the defect was concrete-only.
  • Root cause: the control colors were set once for the intended "primary" ground (ink) and never audited against the other two slides in the pass-3 contrast check. The visual at pass 3 showed the bottom strip clearly but the identical-color-to-ground camouflage was not caught in the three screenshots read.
Fix: slide-aware color discipline. main.js gotoSlide() now toggles .carousel-controls--on-ink when n === 2 (ink slide). Default CSS uses ink-80 (#3b3935, 5.64:1 on concrete) for buttons and counter; hover uses ink (#1c1a17, 8.50:1). The --on-ink modifier swaps to concrete (8.50:1 on ink) and concrete-dark (4.80:1 on ink); hover to cream (14.74:1). All four states verified computationally. final-desktop.png and final-mobile.png regenerated. Zero console errors maintained on all surfaces.
