GRAFT

Three Grafts, Nothing More. The current portfolio's editorial system, kept — with exactly three surgical additions from the monolith. If a fourth move appeared, it was cut.

01 — The Brief

Persona & Concept

Persona seed: A restraint-first editorial art director who rejects redesigns on principle and approves at most three changes per season.

Concept: The portfolio's quiet editorial system, kept — with exactly three monolith grafts and nothing else. Targeted borrowing beats a full reskin.

The Three Grafts

  • Graft 1 — Grid skeleton reveal: 12-column × 8-row grid overlay + registration marks in corners, revealed on hover/focus-within each slide. Registration marks are inside the same hover state — not always-on. Sourced from monolith section 7.
  • Graft 2 — Whisper texture: Three layered repeating-linear-gradient stripes on the olive ground at ≤1.5% alpha each. Light strokes on a dark ground (inverted from monolith's dark-on-concrete recipe). Deepens ~2× inside the INDEX overlay. Sourced from monolith section 8.
  • Graft 3 — One poster-scale heading per surface: clamp(3rem, 12vw, 13rem), letter-spacing: -0.02em, line-height: 0.92. Hero → H1 TREY LUPO. Project → H2 REVENUE TELEMETRY. Outro → H2 THE RECORD IS OPEN. Overlay → H2 INDEX. Exactly one per surface.

What Was Deliberately Excluded

  • No letter-scramble (a fourth borrowed move from ledger/broadside)
  • No scroll-snap (the monolith move that doesn't map to the carousel SPA)
  • No orange body text, glow effects, gradient blobs, or symmetric grids
  • No always-on registration marks (they only appear with the grid)

02 — Signature Technique

Texture Inversion (Graft 2)

The monolith uses dark ink strokes on a light concrete ground. The graft inverts this: light strokes from rgba(227,228,213,…) on the dark olive ground. Three layers at staggered angles and sub-1.5% alpha each produce grain without banding.

/* Graft 2: whisper aggregate texture on the olive ground */
/* Sourced from monolith section 8, inverted for dark bg */
body {
  background-color: #474741;
  background-image:
    repeating-linear-gradient(
      -55deg,
      transparent 0, transparent 4px,
      rgba(227, 228, 213, 0.012) 4px, rgba(227, 228, 213, 0.012) 5px
    ),
    repeating-linear-gradient(
      35deg,
      transparent 0, transparent 7px,
      rgba(227, 228, 213, 0.008) 7px, rgba(227, 228, 213, 0.008) 8px
    ),
    repeating-linear-gradient(
      82deg,
      transparent 0, transparent 11px,
      rgba(227, 228, 213, 0.006) 11px, rgba(227, 228, 213, 0.006) 12px
    );
}

/* INDEX overlay: deeper texture (~2× alpha) */
.overlay {
  background-color: #262622;
  background-image:
    repeating-linear-gradient(-55deg, transparent 0, transparent 4px,
      rgba(227, 228, 213, 0.015) 4px, rgba(227, 228, 213, 0.015) 5px),
    repeating-linear-gradient(35deg, transparent 0, transparent 7px,
      rgba(227, 228, 213, 0.012) 7px, rgba(227, 228, 213, 0.012) 8px),
    repeating-linear-gradient(82deg, transparent 0, transparent 11px,
      rgba(227, 228, 213, 0.010) 11px, rgba(227, 228, 213, 0.010) 12px);
}

Grid Skeleton Reveal (Graft 1)

12-column × 8-row hairlines using repeating-linear-gradient at rgba(227,228,213,0.12). Opacity transitions from 0 to 1 on slide:hover and slide:focus-within. Registration marks (crosshair circles in four corners) share the same CSS trigger — they are inside graft 1, not a separate move.

/* Graft 1: grid overlay + reg marks — same hover/focus state */
.grid-overlay {
  position: absolute; inset: 0;
  pointer-events: none; z-index: 40;
  opacity: 0;
  background-image:
    repeating-linear-gradient(
      to right,
      rgba(227,228,213,0.12) 0, rgba(227,228,213,0.12) 1px,
      transparent 1px, transparent calc(100% / 12)
    ),
    repeating-linear-gradient(
      to bottom,
      rgba(227,228,213,0.06) 0, rgba(227,228,213,0.06) 1px,
      transparent 1px, transparent calc(100% / 8)
    );
  transition: opacity 0.45s cubic-bezier(0.4, 0, 0.2, 1);
}
.slide:hover .grid-overlay,
.slide:focus-within .grid-overlay { opacity: 1; }

/* Registration marks appear with the grid — same trigger */
.reg-mark { opacity: 0; transition: opacity 0.45s cubic-bezier(0.4,0,0.2,1); }
.slide:hover .reg-marks .reg-mark,
.slide:focus-within .reg-marks .reg-mark { opacity: 1; }

Heading Settle (Pass 1 Upgrade)

The H1 hero name settles 8px downward on page load with a long spring ease. Reduced-motion users get the final settled state immediately — full opacity, no transform.

/* Pass 1 upgrade: 8px settle on load */
@keyframes settle-down {
  from { transform: translateY(-8px); opacity: 0; }
  to   { transform: translateY(0);    opacity: 1; }
}
.hero-name {
  animation: settle-down 600ms cubic-bezier(0.16, 1, 0.3, 1) 150ms both;
}
@media (prefers-reduced-motion: reduce) {
  .hero-name { animation: none; opacity: 1; transform: none; }
}

Counter Flicker (Pass 3 Upgrade)

On each slide transition, the mono counter's current digit cycles through two random characters for exactly two animation frames before settling to the real slide number.

/* Pass 3: 2-frame mono flicker — JS */
function updateCounter(instant) {
  const finalText = String(currentSlide + 1).padStart(2, '0');
  if (instant || reducedMotion) {
    counterEl.textContent = finalText;
    return;
  }
  const glyphs = '0123456789';
  const rand2 = () =>
    glyphs[Math.floor(Math.random() * 10)] +
    glyphs[Math.floor(Math.random() * 10)];
  counterEl.textContent = rand2();
  requestAnimationFrame(() => {
    counterEl.textContent = rand2();
    requestAnimationFrame(() => {
      counterEl.textContent = finalText;
    });
  });
}
03 — The Three Surfaces

Slide 1 — Hero

Eyebrow label (Space Mono, 0.6875rem) anchors top-left. H1 "TREY LUPO" at poster scale with 10vh deliberate space below the eyebrow — chosen placement, not centered float. Role line in text-secondary below. Tagline with visible hairline rule at bottom via margin-top: auto.

Slide 2 — Project Poster

Filing reference and category labels top-left. H2 "REVENUE / TELEMETRY" at poster scale dominates two thirds of the viewport height. Description, tabular stats (Space Mono), and dl detail grid anchor the bottom zone. The stats row has a font-variant-numeric: tabular-nums treatment for data alignment.

Slide 3 — Outro / Contact

Thin accent rule (non-text, var(--accent) #F0704C) at top as a zone marker. H2 "THE RECORD / IS OPEN" at poster scale. "Six filings a year. One analyst." in text-secondary. Contact links (GitHub · LinkedIn · treylupo.com) in Space Mono caps with accent-text color (#FA9E78, 4.55 ✓). Credit line in tertiary.

INDEX Overlay

Full-screen ink panel (#262622) with deeper texture (~2× slide alpha). H2 "INDEX" at poster scale top-left. Two-column layout: entry list left (entry 01 is a live <button> navigating to the project slide; entries 02–05 are inert list items at 0.5 opacity). Right column: FILING LOG marginalia in ultra-small Space Mono (not a fourth borrowed move — flavor copy, not a design technique). Grid overlay always-on while overlay is open. Reg marks visible in all four corners.

04 — Critique History
Pass 1

Found

Hero slide: 1fr middle zone was centering the heading in ~700px of space, creating a ~260px void above it. The eyebrow was marooned at top disconnected from the heading. Tagline was clipped by the nav bar (insufficient bottom padding). INDEX overlay right half was empty — no use of the 60% horizontal space to the right of the entry list.

Changed

Removed the three-zone grid approach in favor of flex-column with explicit margin-top on zone-mid. Set bottom padding to 5rem to clear the carousel nav. Added FILING LOG marginalia column to the overlay right side.

Pass 1 Upgrade

Heading settle: H1 "TREY LUPO" enters 8px above final position and settles with cubic-bezier(0.16,1,0.3,1) over 600ms. Already present in initial build code; confirmed via pass-1 screenshot record.

Pass 2

Found

Hero heading at 7vh margin still felt too close to the eyebrow — the eyebrow and name were reading as the same editorial unit rather than hierarchically separated elements. Close button had a box border that created a visible coral/orange rectangle in static QA shots (the focus-visible ring on the first focusable overlay element). Tagline rule (border-subtle 0.08 alpha) was nearly invisible in screenshots.

Changed

Increased zone-mid margin-top to clamp(4rem, 10vh, 7rem) (~90px on 900px viewport). Stripped the close button border — the focus ring alone handles the a11y signal. Changed tagline rule to border-default (0.12 alpha). Changed project stats separator from border-subtle to border-default. Added font-variant-numeric: tabular-nums to stats row.

Pass 2 Upgrade

Texture deepens ~2× behind the open overlay: slide layers use alpha 0.012/0.008/0.006; overlay layers use 0.015/0.012/0.010 on a darker ink ground (#262622 vs #474741), making the grain perceptibly more present without crossing the 1.5% threshold.

Pass 3

Found

All three surfaces and the overlay pass hostile review. Zero console errors. Reduced-motion composition is dignified (hero name fully visible, no collapsed layout). WCAG AA verified computationally: all text pairs ≥ 4.51; #F0704C used only as non-text decoration on slides and as text on ink overlay (5.15 ✓). No fourth borrowed move present.

Changed

No structural changes required — pass 3 was verification and upgrade integration only.

Pass 3 Upgrade

2-frame mono counter flicker: on each slide change, the counter's current digit shows two random glyphs across two requestAnimationFrame cycles (~33ms at 60Hz) before settling to the real number. Suppressed under prefers-reduced-motion.
